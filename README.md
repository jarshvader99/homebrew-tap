# Reezyn tap

```bash
brew install --cask jarshvader99/tap/reezyn
```

Or tap first, then install by name:

```bash
brew tap jarshvader99/tap
brew install --cask reezyn
```

Reezyn updates itself in place, so `brew upgrade` is only needed if you would
rather have Homebrew do it. The cask points at the notarized disk image on
[reezyn.elastikmind.com](https://reezyn.elastikmind.com/).
